How to run in Terminal:

  2. If copying automatically is blocked: in Safari top menu bar, click Edit → Copy.
  3. Switch to the Terminal window (top menu bar: Utilities → Terminal).
  4. In Terminal, click top menu: Edit → Paste.
  5. Press Enter to run.
